Detaylı Çağrı Zinciri — POST /api/chat
# POST /api/chat {message, session_id?, model?, system?}
FastAPI ──► api/routes.py → chat(req)

├──► factory.get_model(req.model) ← lazy singleton, cache'li
│ └── ClaudeModel | DeepSeekModel | KimiModel | OllamaModel

├──► db.get_messages(req.session_id) ← geçmiş mesajlar
│ └── history yoksa db.create_session()

├──► theia_soul.build_system() ← req.system is None ise devreye girer
│ └── importlib ile ~/theia-vault/core/theia_soul.py yüklendi

└──► model.generate(GenerateRequest)
└──► Anthropic / DeepSeek / Kimi / Ollama API çağrısı
└──► db.add_message(user)
└──► db.add_message(assistant, meta={tokens})
└──► return ChatResponse

Tasarım Kararları
✓
BaseModel ABC: core/base_model.py soyut arayüzü tüm model implementasyonlarını aynı generate() / stream() / health_check() sözleşmesine bağlar. Yeni model eklemek factory'ye bir satır.
✓
Lazy singleton factory: Model örnekleri ilk istek geldiğinde oluşturulur, _registry dict'te önbelleğe alınır. Başlangıç süresi düşük, her istekte yeni bağlantı yok.
✓
theia_soul.py entegrasyonu: Sistem promptu importlib ile ~/theia-vault/core/theia_soul.py'den yükleniyor. req.system gönderilirse öncelik onda; gönderilmezse build_system() devreye giriyor. Kişilik tek kaynaktan yönetiliyor.
ℹ
SSE streaming: /chat/stream endpoint'i AsyncGenerator üzerinden data: {chunk} formatında chunk'ları iter eder. Stream bittikten sonra mesajlar DB'ye yazılır — stream sırasında DB bloklama yok.
⚠
Auth yok: Theia Soul şu an kimlik doğrulama içermiyor — kişisel sunucuda Tailscale ile erişim varsayılıyor. İnternete açılacaksa API key / token mekanizması eklenmeli.
